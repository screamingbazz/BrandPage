Job Summary
We are looking for a detail-oriented API QA Engineer to join our engineering team. You will be responsible for ensuring the reliability, performance, and security of our RESTful services. The ideal candidate has a deep understanding of API architecture, can navigate server logs like a pro to hunt down bugs, and possesses the SQL skills to validate data integrity at the source. You will operate within an Agile/Scrum framework, participating in sprints and ensuring quality is delivered continuously. While your primary focus is the backend, you should be comfortable performing functional checks on the frontend to ensure seamless end-to-end integration.
Key Responsibilities
* Agile Participation: Actively participate in Sprint Planning, Daily Stand-ups, Backlog Grooming, and Retrospectives to ensure quality is integrated from the start.
* API Testing: Design and execute comprehensive test suites for RESTful APIs using tools like Postman or Insomnia.
* Issue Debugging: Actively monitor and analyze application logs (using CloudWatch, Splunk, ELK, or terminal-based tools) to identify root causes of failures.
* Database Validation: Write and execute SQL queries to verify that API transactions are correctly reflected in the database.
* Automation: Gradually transition manual test cases into automated scripts using RestAssured (Java) to improve regression efficiency.
* Full-Stack Awareness: Perform "Light" Frontend testing to verify that API responses are correctly rendered on the UI.
* Defect Management: Document clear, reproducible bug reports and track them through the entire SDLC via JIRA or similar tools.
